# Smart-Recovery Discovery - Week 1

Build the discovery and value-case materials that turn Legacy-Trust Bank's collections pain into a credible Phase 1 recommendation.

## How to use this project

1. Follow the curriculum challenges, which say what each phase needs you to produce. Worked examples are in dropdowns on the challenge pages.
2. Write your finished Week 1 outputs into `submissions/`.

## Files explained

- `submissions/` - where you place your completed Week 1 deliverables

## Tests

There is no automated test suite for this week. Your quality checks are built into the curriculum challenges.
